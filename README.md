# 直播洞察 · Douyin Live Insight

面向 Windows 的本地直播资料采集、转写与查询工具，帮助使用者把直播过程整理成便于回顾和分析的资料。

**当前状态：Windows 版本源码已公开，安装包仍在准备，暂未提供新的公开测试安装包。** 旧内部 ZIP 不属于公开测试版。本页描述首期公测范围，不代表所有电脑、网络或平台状态均已验证。

## 首期公测范围

- 添加主播，监测直播状态并采集直播资料。
- 在本机处理音频和转写，使用本地看板查看结果。
- 查询已整理的资料，并通过只读 MCP 接口供兼容的 AI 工具读取。
- 按需配置可选的语言模型分析。基础使用与云模型配置分开；云模型可能产生服务商费用，启用前应了解发送内容及费用。

首期面向 Windows 用户。具体系统要求、前置组件和已验证环境将在测试版发布说明中列明。macOS、Linux 适配不在首期承诺范围。

## 如何参加公测

正式测试包准备好后，会在本仓库的 [Releases](https://github.com/wgs2779294031/douyin-live-insight/releases) 提供下载、安装说明、校验值和已知问题。在此之前，请不要把源代码归档当成可直接安装的软件，也不要使用来源不明的转载安装包。

首轮希望收集以下流程的实际体验：安装、扫码登录、添加主播、采集与转写、查询结果、停止及重启恢复。公测版本可能存在缺陷，建议先使用独立测试目录和可自行承担风险的测试资料，避免把它作为重要资料的唯一副本。

## 反馈问题

请使用 [问题反馈表](https://github.com/wgs2779294031/douyin-live-insight/issues/new/choose)，至少提供：

1. 软件版本与安装包名称。
2. Windows 版本，以及发生问题的大致时间。
3. 能重复操作的步骤、预期结果和实际结果。
4. 必要时提供裁剪后的错误提示或已脱敏日志片段。

**不要上传 Cookie、二维码、登录态、API 密钥、Webhook 地址、完整浏览器配置、真实录音或转写正文。** 截图也应先遮盖账号和个人信息。反馈由使用者主动提交，不要求安装遥测或自动上传诊断资料。

功能建议也欢迎提交。新增功能、跨平台适配及其他大改动需要先讨论并取得项目所有者同意，不承诺收到建议后立即实施。安全漏洞请按 [安全说明](SECURITY.md) 私下报告。
