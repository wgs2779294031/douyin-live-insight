直播监控本地版
安装与使用指南

第一次安装，按下方顺序操作即可。系统会在自己的电脑上保存采集数据，支持弹幕和统计、录音转写，以及把资料交给自己的智能体读取。

本指南随当前测试版安装包生成；请同时核对发布页的完整 ZIP SHA-256。

安装前准备

  • 使用 Windows 10 22H2 x64，或 Windows 11 x64。在 Windows「设置 → 系统 → 关于」中查看系统版本与类型，处理器应显示为「基于 x64 的处理器」。
  • 准备系统 Edge 浏览器和 Microsoft Visual C++ v14 x64 运行库。系统还需有 .NET Framework 4.8 或兼容版本。已有这些组件时可继续下面的步骤。
  • 为下载、解压和首次安装建议预留约 8 GB 空闲磁盘空间，后续录音和资料增长需要额外空间。
  • Python、Node 和转写模型随安装包提供。首次体验可保持内置 AI 关闭，API Key 留空也能采集、转写和读取资料。

缺少组件时，在微软页面下载并安装。VC++ 请选择 X64，.NET 请选择 Runtime。系统出现安装权限提示时，按自己的设备权限处理。

先完整解压

  1. 在电脑上接收并保存「直播监控本地版-含安装指南.zip」。
  2. 右键压缩包，选择「全部解压缩」或解压软件的「解压到」。选择一个短的本地路径，例如 D:\LM-Setup。只有 C 盘时可用 C:\LM-Setup，或自己的下载目录下的短路径。
  3. 等待解压完成。打开解压后的目录，确认能同时看到这份指南、「安装直播监控.exe」和「安装文件」文件夹。
解压出整个文件夹后，从外层的「安装直播监控.exe」进入安装。让它和「安装文件」文件夹放在一起。

双击安装，自动创建桌面图标

  1. 双击解压目录里的「安装直播监控.exe」。
  2. 在窗口中选择安装位置。默认优先使用 D:\LiveMonitor，只有 C 盘时使用当前 Windows 用户的本地应用目录。也可以选择自己的短本地路径。
  3. 点「安装并创建图标」，等待窗口显示安装结果。首次安装会复制较多文件，请等它完成。
  4. 成功后，桌面和开始菜单会出现「直播监控」及「停止直播监控」图标。助手会记住这次安装的位置。

首次安装请选择新的目录，并让安装位置与解压文件夹分开。系统提示缺少运行库时，按本指南开头的官方链接补齐组件后继续。操作进行中点击窗口的关闭按钮，助手会最小化并继续等待完成。

日常启动使用桌面或开始菜单图标。桌面已有同名图标时，新图标名称会带本次安装的标识，按助手的完成提示查找即可。程序、运行数据和同级管理缓存用于后续使用，保留安装后的目录。

进阶排查时使用的命令行安装与检查

只有需要命令行排查时才使用这一节。进入解压目录的「安装文件」，在文件资源管理器顶部地址栏输入 powershell，按回车。

当前命令使用 D:\LiveMonitor。下面所有命令会跟随这里的选择。如果安装助手中选了其他目录，请把命令第一行的安装位置改为那个目录。

点击「复制命令」，回到 PowerShell 粘贴，按回车。如果复制按钮无法使用，可选中整段代码后按 Ctrl+C。每次只执行当前这一步，等出现新的 PS … > 提示后再继续。

检查运行条件

先运行基础检查

checks_passed 表示本次基础检查通过。若显示 checks_passed_limited，请按输出中的缺项和 next_steps 补齐后再检查。

基础检查通过后，再检查转写等运行模块

运行模块检查需要等待。确认输出中 "ok": true 后再开始采集。检查失败时把最后的完整错误信息发给部署人员处理。

启动并打开看板

命令行启动成功时能看到 "ok": true 和 "board_ready": true。浏览器会打开本地看板。

双击图标打开看板，登录并添加主播

双击桌面或开始菜单的「直播监控」。助手会启动后台服务并打开本地看板。第一次加载可能需要等待，遇到错误时按助手显示的信息处理。

首次默认网址为 http://127.0.0.1:8765/。如原安装使用了其他端口，以助手打开的网址为准。

本地看板直接进入页面。抖音平台的扫码登录在下方的专用浏览器中完成。

  1. 进入看板「设置」，找到平台登录区域，先点「准备浏览器」，等准备完成。
  2. 点「打开抖音登录页」，在打开的专用浏览器里用自己的抖音扫码登录。后续采集会使用这个浏览器的登录状态。
  3. 进入「主播」，点「+ 新增主播」。tag 填一个便于识别的唯一标签，例如「我的直播间」。这个标签用于关联数据，建立后请保持一致。
  4. 在「抖音个人主页或 sec_uid」中粘贴主播的完整抖音个人主页链接。请使用自己有权采集的直播间，直接从个人主页复制长链接。
  5. 勾选「采集弹幕/统计」，需要转写时再勾「录音+转写」。首次体验可让「自动实况分析」保持关闭。
  6. 点「保存到名册」。回到「设置」，在平台登录区域的「单次检查目标」中选择刚添加的主播，再点「检查所选主播通道」，根据结果确认该目标当前可查询。
  7. 回到「主播」，如果该行显示「启动」，点它开始采集。如果该行已显示运行中，可继续查看数据。先用一个正在直播的主播测试。

主播开始直播后，在「实时」里查看弹幕和统计。转写要等录音分片封口后处理，先在设置页查看转写队列和进度。首次模型加载可能较慢，任务多时会按顺序排队。

复盘时选择对应主播和日期。在复盘页的资料区点「更新资料」，随后读取或下载已经整理好的内容。成功转写并确认结果后，程序会自动清理对应原音频，转写文本继续保留。失败待处理的音频可能继续占用磁盘，可在设置页观察存储与任务状态。

以后怎样启动和停止

  • 双击「直播监控」，启动后台并打开看板。服务已经运行时会打开现有看板。
  • 双击「停止直播监控」，请求正常停止，并等待当前工作收尾。

关闭网页后，后台监控仍会运行。结束监控请使用停止图标。图标会使用安装时保存的位置，启动器保存在当前用户的本地应用目录中。

遇到问题，按提示处理

看到的情况处理方法
双击安装器后窗口一闪而过确认点的是外层「安装直播监控.exe」。内层 CustomerSetup.exe 是命令行维护入口，需要参数。若外层助手也未打开，请检查上方 .NET 运行环境，并把错误信息交给部署人员。
安装完成，但桌面图标没有出现先在开始菜单搜索「直播监控」。系统保护、目录联接或某些云端重定向桌面可能阻止图标创建，助手会显示结果。开始菜单也没有图标时，保留安装目录并联系部署人员补建。
找不到 CustomerSetup.exe 或路径不存在确认已完整解压，PowerShell 是从真正包含安装器的「安装文件」目录打开。下载目录里可能多套了一层同名文件夹，请进入正确层级。
提示 D 盘不存在回到本指南的安装位置选择器，选择「只有 C 盘」，重新复制相应命令。
缺少 MSVCP140、VCRUNTIME140，或转写模块导入失败从上方微软页面安装或修复 VC++ v14 的 X64 运行库，再重新运行模块检查。若仍失败，提供完整错误码供部署人员排查。
提示需要 .NET，或程序尚未输出就无法打开从上方微软页面安装兼容的 .NET Framework Runtime，完成系统要求的操作后再执行安装命令。
安装目录过长，或提示 install_native_path_too_long改用新的较短安装目录，例如 D:\LiveMonitor。已有失败目录先保留，联系部署人员确认后处理。
显示 manifest_mismatch、bundle_unlisted_path 或校验失败重新取得这份完整分发包并解压到新目录，使用本指南对应的命令。把错误码反馈给部署人员。
浏览器没有打开，或本地网址连不上查看启动命令的结果。只有确认 board_ready 为 true 后再打开本地网址。状态报错或端口被占用时，把结果交给部署人员核对。
主播已添加，但暂时没有数据确认已点主播行的「启动」、主播正在直播、专用浏览器已经登录。检查设置页的平台状态、采集状态和转写队列。
直播已经结束，转写仍在等待查看设置页队列，等待已封口的片段按顺序处理。先用一路直播测试当前电脑的处理速度，再调整采集数量。
提示 75、78、unknown 或占用未确认保留当前目录和现场，把最后的完整错误信息发给部署人员。等待占用或归属问题核对后继续。
